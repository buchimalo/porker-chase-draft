# ポカチェ ドラフト会議

ポーカーチェイス フレンドマッチのチーム分けをドラフト形式で行うための Web アプリ。
Firebase Realtime Database を使って、メインボードと各チームの指名シートがリアルタイムに同期します。

## 画面

| 画面 | ファイル | 用途 |
| --- | --- | --- |
| メインボード | `index.html` | 進行・抽選・管理（配信に映す画面） |
| 指名シート | `team-sheet.html?team=team1` | 各チームが選手を指名する画面 |
| 結果一覧 | `draft-results.html` | 全チームの指名結果 |

## URL パラメータ

| パラメータ | 効果 |
| --- | --- |
| `?team=team1` | 指名シートのチーム指定（省略時はチーム選択画面） |
| `?view=1` | 観戦モード。管理ボタンを隠す（視聴者に共有するURL向け） |
| `?obs=1` | 配信モード。背景透過・指名ボードのみ表示（OBS のブラウザソース用） |
| `?demo=1` | 練習モード。Firebase を使わず端末内だけで動作（本番データに影響しない） |

例:
- 配信用オーバーレイ: `index.html?obs=1`
- 視聴者共有用: `draft-results.html?view=1`
- リハーサル: `index.html?demo=1` と `team-sheet.html?demo=1`（同じPCの別タブ同士は同期します）

## 主な機能

### メインボード
- **指名ボード** — チームごとのカード表示。チームカラー・指名順（スネーク：偶数巡は逆順）・進捗バー。
- **重複の自動検出** — 同じ選手が複数チームに指名されると自動でハイライトし、「抽選が必要です」と表示。
- **抽選（ポーカー勝負）** — 重複した選手ごとに、該当チームへ5枚ずつ配って1枚ずつめくり、役の強さで交渉権を決めます。
  4枚目でリード表示、最後の1枚で決着。当選チーム以外は自動的に「抽選負け」となり再指名待ちになります。
  逆転はおよそ35%の確率で発生します（`js/showdown.js` の `dramaChance` で調整）。

  > 勝者は先に完全ランダム（各チーム 1/N）で決めたうえで、その勝者が勝つ配牌を探しています。
  > 演出のために勝敗を操作してはおらず、勝率は均等、画面に出る役と勝者も常に一致します。
- **再指名不可チェック** — 過去の巡で確定済みの選手が再度指名されると「◯巡目で指名済み」と警告。
- **伏せモード / 一斉公開** — 全チームが送信するまで指名を伏せ、任意のタイミングで一斉公開できます（既定はオフ）。
- **監督（チーム）の管理** — 管理パネルから監督の追加・改名・削除・並べ替えができます。並び順がそのまま指名順（前節上位から）になり、偶数巡は自動で逆順に。各行の 🔗 で、その監督に渡す指名シートのURLをコピーできます。
- **管理パネル（⚙）** — 手動での抽選負け設定、指名の取り消し、総巡目数の変更、候補選手リストの編集、ドラフトのリセット。
- **キーボード操作** — `←` `→` で巡目を移動。

### 指名シート
- チーム選択（端末に記憶）、巡目の自動追従。
- **候補選手リストから選択** — 検索付き。過去の巡で指名済みの選手はグレーアウト、他チームが指名中の選手は `⚔ チーム名` を表示。
- 送信前の確認モーダルに注意事項（再指名不可・重複による抽選）を表示。
- 抽選に負けると赤い「再指名してください」表示に切り替わります。

### 結果一覧
- カード表示 / 一覧表（巡目 × チームのマトリクス）を切替。
- 抽選の記録（対象選手・獲得チーム・抽選負けチーム）を表示。
- 印刷 / PDF 出力に対応。

## データ構造（Realtime Database）

```
draft/
  currentRound: 1
  teams/
    team1/ { id, name, order }   # order = 指名順（1 始まり）
  nominations/
    round1/
      team1/ { playerName, teamName, timestamp, status, attempts? }
  settings/
    totalRounds: 6
    hidePicks: false
    revealed/ { round1: true }
  players: "選手A\n選手B\n..."   # 候補選手リスト（1行1名）
  lottery/
    round1/ { <選手キー>: { playerName, winnerTeamId, winnerTeamName, loserTeamNames, timestamp } }
```

`status` は `confirmed`（確定）または `lost_lottery`（抽選負け）。
`attempts` には抽選に負けた過去の指名が入り、履歴に残ります。

既存データとの互換性を保つため、`settings` / `players` / `lottery` は存在しなくても既定値で動作します。

> 注意: `settings` `players` `lottery` は今回追加したパスです。Firebase のセキュリティルールで書き込みが
> 制限されている場合は、これらのパスへの書き込みを許可してください。

## ファイル構成

```
index.html            メインボード
team-sheet.html       指名シート
draft-results.html    結果一覧
css/style.css         全画面共通のスタイル
js/core.js            Firebase 初期化・共通ロジック（重複検出、順序計算、練習モード等）
js/showdown.js        抽選のポーカー勝負（配牌・役判定・逆転制御）
js/main.js            メインボード
js/team-sheet.js      指名シート
js/draft-results.js   結果一覧
```
